
<h2>Super-Mart-Management-System</h2>
<p>We prepared this project as our <strong>2nd Semester project.</strong>In this project, we have developed a user-interactive interface where users can select products they wish to purchase from our virtual supermarket and add them to their cart. We have utilized file handling in C++ and Object-Oriented Programming (OOPs) concepts to create a robust and efficient system. The project aims to demonstrate our understanding of C++ programming, file handling, and OOPs concepts.</p>
